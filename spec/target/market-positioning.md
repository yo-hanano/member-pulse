# juku-ops ターゲット・価格・運用仮説

この文書は、塾・スクール向け SaaS としての `juku-ops` のターゲット、価格、運用前提を整理する。

現時点の結論は、既存の塾管理システムを全面置換する大型 SaaS ではなく、問い合わせ・入会・契約・請求前後の業務を軽く導入できる低価格な補完システムとして始めること。

## 1. 想定ターゲット

主な対象は、小規模から中規模の塾・スクール運営会社。

特に狙いやすいのは、次の規模。

| セグメント | 教室数 | 生徒数 | 年商感 | 相性 |
| --- | ---: | ---: | ---: | --- |
| 個人塾 | 1教室 | 20〜150人 | 1,000万〜5,000万円 | 単価を上げにくい |
| 小規模チェーン | 2〜5教室 | 100〜800人 | 3,000万〜2億円 | 導入しやすい |
| 中堅塾 | 6〜30教室 | 500〜5,000人 | 1億〜15億円 | 最有力 |
| 大手・地域大手 | 30教室以上 | 5,000人以上 | 10億円以上 | 要件が重い |
| FC本部 | 加盟教室多数 | 数千〜数万人 | 本部次第 | 将来向け |

初期 MVP の主ターゲットは、3〜15教室、300〜2,500人生徒、年商1億〜5億円程度の塾運営会社とする。

## 2. 既存システム前提

この規模の塾は、すでに何らかのシステムを使っている可能性が高い。

想定される既存構成は次の通り。

- 顧客・問い合わせ: Excel、スプレッドシート、kintone、Salesforce、Zoho、LINE管理ツール
- 生徒管理: 塾専用システム、独自 Access、スプレッドシート
- 請求: 口座振替サービス、会計ソフト、決済代行、CSV 運用
- 保護者連絡: LINE 公式、Comiru、Kazasu、連絡アプリ系
- 授業・成績: 塾専用 LMS、教材会社システム、紙
- 経営管理: Excel 集計、BI、会計ソフト

そのため、初期の勝ち筋は「何も入っていない会社に売る」ではなく、分断された運用のすき間に入ること。

## 3. 競合環境

競合製品は多い。

代表的には、Comiru のような塾向けオールインワン業務管理システムがある。保護者連絡、業務管理、請求、本部機能、カスタマイズ開発まで広く提供しているため、正面からの全面競合は避ける。

ほかにも、低価格を打ち出す生徒管理システム、スクール管理システム、入退室管理、LINE 連絡ツール、kintone、スプレッドシート運用が実質的な競合になる。

競合前提での方針は次の通り。

- オールインワン塾管理システムとして売らない
- 保護者連絡、出欠、成績、授業報告に正面から入らない
- 既存システムとの併用を前提にする
- 問い合わせ、体験、入会、契約、請求前後、本部横断の見える化に絞る
- 低価格だが、サポートや個別対応を限定する

## 4. プロダクトの位置づけ

`juku-ops` は、塾・スクール向けの軽量 CRM + 契約/請求前管理 + 本部管理システムとして位置づける。

想定コピーは次の通り。

> 月額5,000円から使える、塾向けの問い合わせ・入会・請求前管理システム。既存の塾管理システムや LINE 運用と併用できます。

主に扱う業務は次の範囲。

- 問い合わせ管理
- 体験・面談・入会進捗
- 生徒・保護者・契約情報
- 請求ステータス、未収、休会、退会
- 教室横断のリード数、入会率、在籍数、未収、退会率

## 5. 価格プラン

プランは細かく増やさず、Solo、Team、Business の3つにする。

| プラン | 月額 | 含まれる範囲 | サポート |
| --- | ---: | --- | --- |
| Solo | 4,980円 | 1教室 / 生徒150人 / スタッフ3人 | メールのみ / 5営業日以内 |
| Team | 14,800円 | 5教室 / 生徒800人 / スタッフ20人 | メールのみ / 3営業日以内 |
| Business | 39,800円 | 15教室 / 生徒2,500人 / スタッフ80人 | メールのみ / 2営業日以内 |

Business 以上は固定プランを増やさず、超過課金で拡張する。

- 追加教室: 2,000円/月・教室
- 追加生徒: 5,000円/月・1,000人
- 追加スタッフ: 1,000円/月・10人

教室数だけで課金すると、複数拠点を無理に1教室として運用される可能性がある。そのため、教室数、生徒数、スタッフ数を組み合わせる。

## 6. 教室の定義

課金上の「教室」は、単なる名称ではなく業務上の管理単位とする。

教室としてカウントする条件は次の通り。

- 生徒を所属させる拠点
- 問い合わせ/体験申込の受け皿
- 請求・契約・売上集計の単位
- スタッフ権限を分ける単位
- 住所・電話番号・ブランド名・校舎名を持つ単位
- レポートで個別集計したい単位

料金表や利用規約では、次のように表現する。

> 教室とは、問い合わせ受付、契約・請求、スタッフ権限、売上集計を分けて管理する運用拠点を指します。

複数拠点を1教室にまとめると、教室別フォーム、権限、売上集計、通知設定、担当者設定、レポートが分けられず不便になる設計にする。

## 7. サポート方針

個人運営を前提に、標準サポートはメールのみとする。

電話、Zoom、訪問、チャットは標準提供しない。

無料サポートに含める範囲。

- ログインできない
- 画面の使い方が分からない
- エラーが出る
- 登録/編集/CSV 出力の基本操作
- 不具合報告

無料サポートに含めない範囲。

- 業務フローの設計相談
- データ移行作業
- 請求ルールの整理
- 帳票カスタマイズ
- 他システム連携
- 顧客の代わりのデータ入力
- 電話/Zoom での操作説明

有償対応の目安は次の通り。

| 内容 | 料金目安 |
| --- | ---: |
| Zoom相談 | 10,000円 / 60分 |
| 初期設定代行 | 30,000円〜 |
| CSV移行代行 | 30,000円〜 |
| 請求ルール整理 | 50,000円〜 |
| 操作説明会 | 30,000円 / 回 |
| 個別帳票作成 | 30,000円〜 |
| 外部連携 | 個別見積 |

低価格で継続提供するため、サポート範囲は明確に限定する。

## 8. 個人運営の見せ方

個人運営であることは隠さない。ただし、営業上は前面に出さない。

サイトや営業資料では、サービス名を主語にする。

- 「個人開発」「ひとりで運営」は前面に出さない
- 低価格の理由は、標準機能に絞り、メールサポート中心で提供しているためと説明する
- 契約、特商法、プライバシーポリシー、利用規約では運営者情報を正しく出す
- 個人情報保護、バックアップ、障害時対応、サポート範囲を明文化する

避ける表現。

- 個人なので安いです
- 副業で作っています
- できる範囲で対応します
- 電話は無理です

使う表現。

- 標準サポートはメール対応です
- 電話・訪問サポートは提供していません
- 個別設定・移行作業は有償です
- バックアップと障害対応方針を公開しています
- 利用規約にサービス提供範囲を定めています

## 9. サーバー費用

初期は、さくらのクラウドで月1万〜1.5万円程度を目標にする。

最小構成の目安。

| 構成 | 月額目安 |
| --- | ---: |
| アプリサーバー 2コア/4GB | 約4,620〜4,950円 |
| SSD 40GB | 約1,540円 |
| PostgreSQL アプライアンス 10GB | 2,750円 |
| オブジェクトストレージ 100GiBまで | 495円 |
| 合計 | 約9,500〜10,000円/月 |

初期構成では、アプリサーバー1台に frontend/BFF/backend/Redis を同居させ、DB はさくらの DB アプライアンスを使う。

売上が月10万円を超えたら、次の構成へ拡張する。

- Web/BFF サーバー分離
- Backend サーバー分離
- Redis 用小型サーバー分離
- PostgreSQL 30GB プラン
- 監視、ログ、バックアップ強化

この段階の月額目安は2万〜3万円台。

## 10. 現時点の結論

初期戦略は次の通り。

- 競合の多いオールインワン塾管理システム市場に正面から入らない
- 既存システムのすき間である問い合わせ・入会・契約・請求前後に絞る
- 既存の塾管理システムや LINE 運用と併用できる形にする
- 価格は Solo 4,980円、Team 14,800円、Business 39,800円を基本にする
- Business 以上は教室数、生徒数、スタッフ数で従量拡張する
- 標準サポートはメールのみ
- 個別対応、移行、運用相談、外部連携は有償にする
- サーバー費用は初期月1万〜1.5万円を目標に抑える

## 11. 代替方向性: 会員マーケティング CRM

塾管理システムは、Comiru や Jukugo のような強い競合があり、保護者アプリ、請求、生徒管理、職員管理、基本業務管理まで広く押さえられている。

個人運営で正面から塾管理 SaaS を作ると、機能網羅、移行支援、個別業務対応、サポート負荷で不利になりやすい。

そのため、マーケマンのような D2C 向けマーケティング支援システムを、会員ビジネス向けにずらす方向も検討する。

### 11.1 位置づけ

会員管理システムではなく、会員マーケティング CRM として位置づける。

既存の会員管理、予約、決済、入退館、業務管理は置き換えない。

CSV インポートや外部データ連携で、継続率、解約予兆、LTV、休眠会員、キャンペーン対象者を見える化する補完ツールにする。

想定コピーは次の通り。

> 既存の会員管理・決済システムの CSV から、継続率・解約予兆・LTV を見える化する会員マーケティング CRM。

### 11.2 想定業界

対象になり得る会員ビジネス。

- フィットネスジム
- パーソナルジム
- ヨガ・ピラティス
- エステ・美容サロン
- 整体・治療院
- 習い事・スクール
- オンラインサロン
- ファンクラブ
- サブスクサービス
- 定期購入系 D2C
- コミュニティ運営
- コワーキングスペース

共通点は、会員、契約、継続、休眠、解約、LTV が重要であること。

### 11.3 扱う指標

初期で扱う指標。

- 新規会員数
- 有料転換率
- 継続率
- 解約率
- 休眠率
- LTV
- 月次売上
- プラン別売上
- 来店/利用頻度
- 最終利用日
- 解約予兆
- キャンペーン反応
- セグメント別売上

業務管理ではなく、マーケティングと継続率改善に寄せる。

### 11.4 初期 MVP

初期 MVP は、既存システムを置き換えずに使える範囲へ絞る。

- 会員 CSV インポート
- 売上/契約 CSV インポート
- 会員一覧
- セグメント作成
- 解約予兆リスト
- 休眠会員リスト
- LTV/継続率ダッシュボード
- キャンペーン対象者抽出
- CSV エクスポート

予約、決済、契約処理、入退館、スタッフ管理、現場業務管理には入らない。

### 11.5 価格案

会員数ベースのシンプルな価格にする。

| プラン | 月額 | 対象 |
| --- | ---: | --- |
| Starter | 4,980円 | 会員1,000人まで |
| Growth | 14,800円 | 会員5,000人まで |
| Business | 39,800円 | 会員20,000人まで |
| Business 超過 | +5,000円 | 追加10,000会員ごと |

標準サポートはメールのみ。

初期設定、CSV 整形代行、データ移行、外部システム連携は有償にする。

### 11.6 塾向けより良い点

会員マーケティング CRM は、塾管理 SaaS より個人運営に向いている可能性がある。

- 業務フローの個別差分に深く入らなくてよい
- 保護者アプリや請求例外に巻き込まれにくい
- CSV 連携だけで始められる
- サポートをメール中心にしやすい
- 複数業界へ横展開できる
- 継続率改善や LTV 向上として売上貢献を説明しやすい
- 既存システムの置き換えではなく、上に乗る分析・施策ツールとして売れる

### 11.7 注意点

「会員管理システム」と名乗ると、予約、決済、契約、店舗業務、入退館、スタッフ管理まで期待される。

そのため、初期は「会員マーケティング CRM」「継続率改善ツール」「LTV 分析ツール」のように、マーケティング・分析・施策対象抽出に絞って見せる。

この方向に進む場合、`juku-ops` のドメインを塾業務から会員ビジネス全般へ広げるため、既存 MVP スコープは大きく見直す。
